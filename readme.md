# SberAuto Analytics - ETL система

## Описание проекта
Полнофункциональный ETL-пайплайн для обработки данных Google Analytics с сравнительным анализом
16.7 млн исторических записей.

## 📊 Основной отчет
[**sberauto_etl_report.pdf**](sberauto_etl_report.pdf) - Полный аналитический отчет и документация

## 🏗️ Архитектура решения
- **Источник данных**: JSON-файлы Google Analytics
- **Обработка**: AirFlow + Python ETL с MD5-дедупликацией
- **Хранилище**: Аналитическая база данных DuckDB
- **Аналитика**: Сравнение исторических и инкрементальных данных

## 📁 Структура проекта
- `sberauto_etl_pipeline.ipynb` - Анализ данных в Google Colab (16.7 млн записей)
- `airflow_files/` - Код production ETL-пайплайна
- `sberauto_etl_report.pdf` - Финальный аналитический отчет

## 🚀 Быстрый старт
1. Изучите PDF-отчет для общего понимания проекта
2. Запустите Colab-ноутбук для исследования данных
3. Разверните AirFlow DAG для production-обработки

## 📈 Ключевые инсайты
- Рост мобильного трафика: 79.3% → 92.6% (+13.3%)
- Увеличение вовлеченности пользователей: +7%
- Оптимизация географического распределения
- Выявление паттернов пользовательского поведения

## 🔧 Технические особенности
- **Идемпотентность**: Безопасные повторные запуски
- **Дедупликация**: MD5-контроль обработанных файлов
- **Масштабируемость**: Поддержка больших объемов данных
- **Мониторинг**: Полное журналирование процессов

## 📋 Требования
- Python 3.8+
- DuckDB 0.9.2+
- AirFlow 2.6+ (для production-развертывания)
